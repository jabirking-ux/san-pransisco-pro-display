Web & CSS Integration

Import san-pransisco.css in your HTML or bundler to use the complete family with full fallback support: 

/* 1. Link the stylesheet */
<link rel="stylesheet" href="san-pransisco.css">

/* 2. Apply to headings and display elements */
h1, h2, h3, .display {
  font-family: 'San Pransisco Pro Display', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  letter-spacing: -0.02em;
  -webkit-font-smoothing: antialiased;
}
